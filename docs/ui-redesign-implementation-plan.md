# UI redesign — current entry point

The September 2026 acceptance plan is [archived](archive/ui-redesign-implementation-plan.md).
Its unfinished items are historical evidence, not an automatically authorized
backlog. Use [DESIGN.md](../DESIGN.md) and the current human design brief.

Current selection (26 October 2026): implement **Mint Garden** and **Lavender
Club** first, sharing layout and components. Other themes remain concepts.
Owner, coach, reception and customer experiences are mobile-first and responsive;
ops is desktop-first. A component-library decision is still pending; neither
shadcn/ui nor MUI is approved for installation by this documentation cleanup.

A new design-system implementation plan will follow cleanup and the CI work;
this entry point does not start that implementation or certify the old UI.
